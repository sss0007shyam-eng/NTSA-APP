# NTSA website

Static landing page for the NTSA app (SSS Enterprises): home, about, FAQ,
privacy policy, terms & conditions, refund policy and contact.

Plain HTML and CSS, no build step. Deploy the repository root as a static site
(Vercel, Render Static Site or Netlify).

Before going live, fill the highlighted placeholders: `[EMAIL]`, `[PHONE]`,
`[NAME]` (grievance officer), `[DATE]` and `[X]` (refund days) in
`privacy-policy.html`, `terms.html`, `refund-policy.html` and `contact.html`.
